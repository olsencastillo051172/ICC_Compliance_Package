## 1. Purpose
This document serves as the **evidence index and traceability map** for IA Compliance Core (ICC).  
It identifies compliance‑relevant artifacts published in this repository and clarifies their scope, intent, and limitations.

ICC is designed to **enable compliance readiness and governance workflows**.  
It does **not** provide legal advice, regulatory certification, or official compliance attestation.

## 3. Operational Evidence (Generated by ICC)

### Policy Drafts
- **Source:** Advisory drafts generated per regulatory source  
- **Format:** Markdown / Git repository  
- **Verification:** At least 1 draft per configured regulatory source  
- **Location:** `policy-drafts/` (branch: main)  

### Evidence Seals
- **Source:** Blockchain anchoring (Polygon / Solana)  
- **Format:** Transaction hash  
- **Verification:** Minimum 3 seals per approved PolicyDraft  
- **Location:** Blockchain explorer (hash references stored in `evidence-seals/`)  

### Simulation Reports
- **Source:** Risk Simulator (sandbox only)  
- **Format:** JSON / PDF  
- **Verification:** Final score > 0.85  
- **Location:** `icc-risk-simulations/` (S3 / Azure Blob)  

### MCP Audit Logs
- **Source:** Model Context Protocol (MCP)  
- **Format:** PostgreSQL logs  
- **Verification:** ≥100 entries with non‑null `evidence_id`  
- **Location:** `audit_logs` table
